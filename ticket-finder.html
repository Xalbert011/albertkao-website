找票機器人

7 個 Claude AI Prompt × 1 個 Python 自動監控機器人

← 返回 Albert Kao 個人頁面

把以下任一段 Prompt 貼入 Claude.ai，即可讓 AI 幫你搜尋便宜機票、分析票價趨勢、找最划算日期。
把 【藍色標籤】 替換成你的實際資訊即可使用。

1

隱藏航班搜尋器

列出廉航、區域航空、小眾航空，依實際總價格排序，找出主流平台看不到的選項。

列出未來 【X 週】 內從 【出發地，例如台北 TPE】 到 【目的地，例如東京 NRT】 的所有航班，包含廉航、區域航空、以及較少人知道的航空公司。

請依「實際總價格（含稅費行李）」由低到高排序，並分別列出：
・直飛選項
・1 次轉機選項（中東 / 東南亞樞紐）
・其他小眾航空組合

附上各航班的起飛時間、飛行總時數與最後查詢日期。
2

票價策略分析

分析歷史趨勢，告訴你現在的票價是高是低，該立刻訂還是繼續等。

分析 【出發城市，例如台北】 到 【目的地，例如洛杉磯】 在 【月份，例如 2026 年 8 月】 的歷史機票價格趨勢。

我目前看到的價格是 【目前價格，例如 NT$35,000】，請告訴我：
1. 這個價格是高於還是低於歷史平均水平？
2. 根據歷史規律，我應該現在訂還是再等等？
3. 我應該設定多少作為目標票價（等到這個價位就立刻訂）？
4. 這條航線最便宜的「訂票時機」通常是出發前幾天？

請用圖表或表格呈現月均價與我的目前價格的相對位置。
3

找出最適合的日期

比較目標日期前後的所有出發 / 回程組合，找出 3 個最划算的選項並說明理由。

我想在 【目標日期，例如 2026 年 7 月初】 前後 【X 天，例如 5 天】 內出發，從 【出發地】 飛往 【目的地】，停留約 【幾天，例如 7 天】。

請從 Expedia、Skyscanner、Trip.com 等平台，比較這段時間內所有出發與回程日期組合的票價，列出 3 個最划算的選項，並說明：
・為什麼選出這 3 個組合？
・出發日與回程日是否完全在目標範圍內？
・有哪些注意事項（如週末溢價、假期高峰）？

請以表格呈現，欄位包含：出發日、回程日、天數、航空公司、價格（含稅）、直飛 / 轉機。
4

觸發降價通知

找出目前真的有效的免費降價追蹤服務，並建立一份可立即使用的追蹤表格。

我想監控 【目的地，例如東京】 的機票降價，出發地是 【出發地，例如台北】，目標出發月份是 【月份】。

請幫我：
1. 研究並列出目前（2026 年）真的有效、免費的機票降價追蹤服務（Google Flights、Skyscanner、Hopper、Kayak 等），並說明各自的設定步驟（不要只列名字，要附上具體操作方式）。
2. 建立一份 Google Sheets 追蹤表格，欄位包含：日期、出發地、目的地、查詢價格、歷史均價、是否低於門檻、來源平台。
3. 告訴我今天就能開始用的完整設定流程，讓我在價格低於 【目標金額，例如 NT$8,000】 時收到通知。
5

避開昂貴日期

製作視覺化日曆熱圖，標出整個月最便宜與最貴的旅遊時段。

搜尋 【出發地，例如台北 TPE】 到 【目的地，例如洛杉磯 LAX】 在 【月份，例如 2026 年 6 月】 所有可能的來回日期組合票價。

請抓取真實價格資料，並製作一個視覺化的日曆熱圖（顏色深淺代表票價高低），讓我一眼看出最便宜的旅遊時段。

要求：
・停留天數以 【幾天，例如 7 天】 為基準
・特別標記任何總價低於 【預算，例如 NT$25,000】 的平日組合（用星號 ★ 標記）
・附上資料來源與查詢時間
6

破解訂票系統

深入旅遊駭客論壇與航空部落格，找出 5 個目前真的有效的省錢訂票技巧。

立即深入研究旅遊駭客論壇（PTT 旅遊板、背包客棧、FlyerTalk）與航空公司部落格。

找出 5 個目前（2026 年）真的有效、可以降低 【出發地 → 目的地，例如台北 → 歐洲】 機票價格的訂票技巧。

要求：
・不要泛泛建議（如「提早訂」），要有具體的操作步驟
・每個技巧請附上真實案例或來源連結，讓我可以自行驗證
・說明適用的航空公司或適用條件
・若技巧有風險或注意事項也請一併說明
7

建立我的機票機器人

讓 Claude 幫你寫一個 Python 監控程式，價格低於門檻時自動寄 Email 通知（可搭配下方現成版本使用）。

幫我寫一個可運作的 Python 程式，監控我指定的 3 個目的地機票價格：
・【出發地 → 目的地 1，例如 TPE → NRT，門檻 NT$8,000】
・【出發地 → 目的地 2，例如 TPE → BKK，門檻 NT$6,000】
・【出發地 → 目的地 3，例如 TPE → LAX，門檻 NT$28,000】

功能需求：
1. 定期抓取票價資料（使用 Amadeus 免費 API 或其他可靠來源）
2. 每次抓取後將結果存入 price_history.csv
3. 當價格低於設定門檻時，發送 HTML 格式的 Email 通知
4. 支援 --once 模式（單次執行，配合 cron 排程使用）
5. 支援 --dry-run 模式（不發 Email，只顯示結果）

請建立以下可下載的檔案：
・flight_monitor.py（主程式）
・config.example.yaml（設定範本）
・.env.example（環境變數範本）
・requirements.txt（依賴套件清單）
・README.md（部署說明）

⬇️ 現成的 Python 機票機器人（立即可用）

上方第 7 個 Prompt 已由 Claude 實作完成，使用 Amadeus 免費 API，支援 Email 通知與 CSV 歷史紀錄。

快速部署步驟：
  1. 至 developers.amadeus.com 免費申請 API Key
  2. 下載下方所有檔案，放到同一個資料夾
  3. 執行 pip install -r requirements.txt
  4. 複製 config.example.yaml 為 config.yaml，填入你的設定
  5. 複製 .env.example 為 .env，填入 API Key 與 Email 密碼
  6. 執行 python flight_monitor.py --dry-run 測試
  7. 用 cron 設定自動排程（見下方範例）

0 */6 * * * cd /path/to/flight-bot && python flight_monitor.py
